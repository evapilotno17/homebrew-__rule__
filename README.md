# Evapilotno17 __rule__

## How do I install these formulae?

`brew install evapilotno17/__rule__/<formula>`

Or `brew tap evapilotno17/__rule__` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "evapilotno17/__rule__"
brew "<formula>"
```
